# 모양 사용자 테스트 데이터

모든 인물과 내용은 테스트용으로 만든 가상 데이터입니다. 실제 계정이나 개인 정보가 아닙니다. 기준 시점은 2026-11-26이며 날짜와 모임 상태는 고정된 예시입니다. 현재 날짜에 맞춰 사용하려면 일정과 상태를 함께 조정하세요.

| 파일 | 내용 |
| --- | --- |
| users.json | 가상 사용자 8명과 온보딩 답변. 선택지 코드와 직접 입력 조건은 설문 구현을 따릅니다. |
| records.json | 사용자 6명의 그림 설명과 감정 기록 카드. 이미지 파일은 포함하지 않아 imageUrl은 null입니다. |
| conversations.json | 각 그림에 연결된 AI 대화 예시. 진단이나 실제 AI 생성 결과가 아닙니다. |
| programs.json | 기록에 연결된 개인 프로그램: 진행 중과 완료 상태. days는 일요일 0부터 토요일 6입니다. |
| meetings.json | 예약 모임과 진행 중인 모임. startAt은 Unix 밀리초이며 참가자 ID를 포함합니다. |
| meeting-chat.json | 진행 중인 모임의 참여자, 단계, 메시지와 그림 공유 예시. |

사용자 id, userId, drawingId, recordId와 meetingId로 파일 간 관계를 확인할 수 있습니다. 그림 공유의 `meeting-sample:drawing`은 앱 내부 예시 이미지 식별자입니다.

이 파일들은 테스트 시나리오용 데이터 모음이며 API 응답이나 브라우저 저장소에 자동으로 주입되지 않습니다. `userId`, `hostUserId`, `participantUserIds` 등은 관계를 설명하기 위해 추가한 필드이므로 실제 API나 기존 mock 저장소에 적용할 때 해당 형식에 맞게 변환해야 합니다. 온보딩 화면의 개발용 선택지는 `/onboarding?preview`가 아니라 설문 경로에서 `?preview`로 확인할 수 있습니다.

## API 정상 응답 예시

- `my-info-api.json`: 내 정보 조회와 닉네임·양 색상 변경의 요청 및 성공 응답. 기준 사용자는 구름양입니다.
- `meeting-api.json`: 모임 목록·필터·내 모임·상세·생성·참여·입장·시작·단계 전환·메시지 조회/전송·종료·나가기·취소·회고 카드의 요청과 성공 응답.

API 예시는 저장된 OpenAPI 명세와 프런트엔드의 코드값을 참고했습니다. 각 항목은 독립적인 시점의 예시이므로 수정 요청 후 다른 응답이 자동으로 바뀌지 않습니다. 모임 ID 201~206은 API 예시 전용이며 기존 `meetings.json`의 ID와 별개입니다. 날짜는 고정되어 있고 이미지 URL은 경로 예시로 실제 이미지가 포함되어 있지 않습니다. 자동 응답 서버나 앱 연결은 포함하지 않습니다.
